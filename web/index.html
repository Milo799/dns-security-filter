离线情报源
本地离线威胁情报 · 整源导入 · 零 API 调用 · 零 Key
💾 离线情报源说明
本地匹配内置 6 个开源威胁域名库（hagezi 系 / StevenBlack / URLhaus / OISD），整源导入本地存储，运行时内存缓存 O(1) 匹配。
零 API / 零 Key与在线情报源不同，匹配全程在本地完成，不产生外部查询，不依赖公网可达。
匹配方式域名精确 + 逐级父域匹配（evil.example.com 可命中 example.com 条目）。
自动更新实际周期取「全局间隔」与「源内置周期」的较小值，urlhaus 保持 30 分钟高时效；单源失败不影响其他来源与服务。
优先级低于人工白/黑名单，高于在线情报源。
